# Ingredient Image Prompts

Images for the **Our Ingredients** page cards (`ingredients.html`). There is one image per ingredient.

## How to use
1. Paste the **Style block** below, followed by the ingredient's own prompt, into your image generator (Midjourney, DALL·E, Firefly, Ideogram, etc.).
2. Export at **1280 × 800 px (16:10)** as **WebP**, ideally under **150 KB**.
3. Save the image as `public/assets/ingredients/<filename>` using the exact filename from the table. The page picks it up automatically.
   Until an image exists, its card shows a tinted letter placeholder, so you can add images one at a time.

## Style block (use for every image so the set matches)
> Studio botanical still life photograph, soft diffused natural window light from the left, warm off-white linen background, muted sage-green and cream palette, subject centered with generous negative space, shallow depth of field, gentle realistic shadows, clean premium wellness-brand aesthetic, high detail, no text, no labels, no logos, no hands, no people, 16:10 landscape.

Midjourney users can append: `--ar 16:10 --style raw`
